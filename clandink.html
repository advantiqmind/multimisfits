Clan Dink Settings

Copy the clan's Dink plugin settings and import them into RuneLite. This keeps everyone's notifications synced to our chest channel.

First-time Setup

  1. Download the Dink plugin on RuneLite
  2. Click Copy Settings below
  3. Type ::dinkimport all in OSRS game chat

Updating Settings

  1. Click the Reset button at the bottom of the Dink plugin settings panel
  2. Click Copy Settings below
  3. Type ::dinkimport all in OSRS game chat
